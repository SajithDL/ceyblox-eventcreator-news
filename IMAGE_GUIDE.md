# Feed Image Guide

Main feed/hero images: **1600×700 px (16:7)**.

Related article images: **1280×720 px (16:9)**.

Preferred formats: WebP or JPG. Use unique filenames when replacing an image during GitHub testing because raw/CDN image caching can briefly keep the previous file when the same filename is reused.

Current illustrative image filenames expected by the included JSON:

- `up_0001/images/night-event-build.webp`
- `up_0002/images/preset-workshop.webp`
- `up_0003/images/staff-control-room.webp`
- `up_0004/images/event-library-night.webp`
- `up_0005/images/theme-event-scene.webp`

The images are development artwork, not guaranteed literal in-game screenshots.
